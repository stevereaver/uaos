# Documentation

Human-readable manuals and guides shipped in `documentation/`.

- [Dos Manual.pdf](/documentation/dos_manual_pdf.md) — DOS & Scripting Manual, generated from `Dos_Manual.md` via pandoc/pdfTeX.
- [manual.pdf](/documentation/manual_pdf.md) — Technical Reference Manual, compiled from `manual.tex` via pdfLaTeX.

Other artifacts in `documentation/` (not yet tracked as concepts): `manual.md`/`manual.tex` sources, `uaos.guide` (AmigaGuide), `index.html`/`manual.html` (built by `build_html.sh`), `CODE_SOURCES.md`, `Shell_Audit_Report.md`, `scancode_report.{json,md}` (ScanCode license scan), and the historical design/investigation docs `HANDLER_SYSTEM_PLAN.md` and `68020_mmu_investigation_report.md`.
