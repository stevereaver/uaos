# Concepts

Cross-cutting concepts that span multiple subsystems.

- [Icons](/okf/concepts/icons.md) - Amiga `.info` icon loading, selected-state rendering, and desktop selection interaction.
- [M68k Emulation](/okf/concepts/m68k_emulation.md) - How UAOS runs classic Amiga binaries.
- [Thunking](/okf/concepts/thunking.md) - Calling native libraries from emulated M68k code.
- [Userspace & Syscalls](/okf/concepts/userspace_syscalls.md) - The Ring-0 task execution model, `INT 0x80` syscall ABI, and native userspace programs.
- [Network Stack](/okf/kernel/net/index.md) - TCP/IP networking, DHCP, DNS, NTP, and the BSD socket API for emulated tasks.
